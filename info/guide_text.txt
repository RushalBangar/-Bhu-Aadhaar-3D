1. Executive Summary & Product Vision 
●​ Project Name: Bhu-Aadhaar 3D (3D-VLAD: Vertical Land Administration 
Domain) 
●​ Problem Statement ID: SIH26011 
●​ Ministry: Ministry of Rural Development / Department of Land Resources 
(DoLR) 
●​ Core Mission: Bridge India's 2D land registry system into an interactive, 
volumetric 3D digital cadastre for high-rise buildings, apartment units, 
basements, and parking spaces, eliminating multi-mortgage fraud and 
boundary disputes. 
2. Comprehensive Application Flows & 
User Journeys 
User Journey 1: Citizen / Homebuyer (Public Verification 
Flow) 
1.​ Landing Page: Citizen lands on a clean, modern GovTech portal with a 
prominent search bar: "Search by 2D ULPIN, Survey Number, or 
City/Building Name". 
2.​ Search & Auto-Complete: Citizen enters a building name (e.g., "Galaxy 
Heights, Nashik") or land survey number. 


=== PAGE 2 ===
3.​ Map Centering: The 2D map glides smoothly and centers on the target land 
parcel. 
4.​ 3D Extrusion: The flat building footprint extrudes upwards into an 
interactive 3D model with realistic floor heights. 
5.​ Interactive Unit Selection: Citizen clicks on Floor 4 -> Unit 402. The 
camera smoothly orbits and zooms toward Floor 4. 
6.​ Property Card Sheet: A right-hand panel slides open showing: 
○​ Legal 3D-ULPIN (14MH2704291845-FL04-U402-Z12.5) 
○​ Ownership status (Registered Owner Name, Registration Date) 
○​ Carpet area and balcony measurements 
○​ Assigned Basement Parking Slot (e.g., P-14) 
○​ Loan/Mortgage Status (e.g., "Active Mortgage with SBI" or "Clean 
Title - No Liens") 
7.​ Download Digital 3D Property Card: Citizen can click "Download Verified 
3D Property Card" (PDF with QR code). 
User Journey 2: Revenue Officer / Municipal Admin 
(Mutation & Approval Flow) 
1.​ Authentication: Officer logs in via secure role-based access. 
2.​ Pending Mutation Requests: Officer views a list of pending flat transfers, 
builder subdivision plans, or new unit registrations. 
3.​ 3D Spatial Audit: Clicking a request opens the 3D model. The proposed flat 
or newly added floor is highlighted in amber. 
4.​ Conflict Check: Officer runs "Automated Conflict Scan". The system 
checks whether the builder's declared boundary overlaps with common 
areas, fire exits, or adjacent units. 
5.​ One-Click Approval: If conflict score is 0, the officer clicks "Approve 
Mutation". The system assigns the official permanent 3D ULPIN and 
updates the immutable ledger. 
User Journey 3: Bank / Financial Institution (Collateral 
Verification Flow) 
1.​ Lien Check Interface: Bank loan officer enters the 3D ULPIN provided in a 
loan application. 


=== PAGE 3 ===
2.​ Instant Verification: The system displays the exact 3D location of the flat 
and checks if any other financial institution has already registered a lien. 
3.​ Double-Mortgage Prevention: If an active lien exists, the system flags a 
high-priority warning: "Active Mortgage Registered by Bank of Baroda on 
14-Jan-2025", completely preventing multi-bank collateral fraud.

Micro-Interactions & Animations 
1.​ Raycast Hover: When the mouse hovers over an apartment unit, its opacity 
changes from 0.4 to 0.7 with a subtle cyan edge wireframe. 
2.​ Unit Selection Glow: Clicking an apartment unit transitions its mesh material 
into emerald green (#10B981) with a soft bloom glow, while non-selected 
units dim to 0.2 opacity. 
3.​ Exploded View Toggle: Clicking "Explode Floors" animates every floor 
moving vertically apart along the $Z$-axis by 2.5 meters (using a smooth 
cubic easing curve), allowing users to see inside middle floors effortlessly. 
4.​ Conflict Shake Animation: If a user tests duplicate parking or unauthorized 
terrace construction, the affected 3D geometry pulses red with a gentle 
3-frame haptic shake. 
4. Technical Architecture & Developer 
Instructions 
System Architecture Overview 
●​ Client Layer: Pure HTML5, Modern CSS3 (Glassmorphism, Flexbox/Grid), 
and Vanilla JavaScript (ES6 Modules). No Node.js build steps or npm 
dependencies required. 
●​ 3D Graphics Engine: Three.js loaded via CDN (cdnjs / jsdelivr) along with 
OrbitControls. 
●​ Database & Spatial Backend: Supabase (PostgreSQL + PostGIS) connected 
directly via the official Supabase JavaScript client CDN script 
(@supabase/supabase-js). 
●​ Optional Backend: Node.js (Express) or Python (FastAPI) on Render free 
tier, or direct Supabase client-side queries with Row-Level Security. 
●​ Deployment: GitHub Pages or Vercel / Netlify (zero-config, instant 1-click 
deployment). 
Vanilla HTML/CSS/JS File Structure 
●​ index.html: Canvas container, top navigation bar, search bar, and slide-out 
property inspector card.

export function generate3DUlpin(params) {​
  const floorFormatted = params.floorNumber < 0​
    ? `B${Math.abs(params.floorNumber)}`​
    : `FL${params.floorNumber.toString().padStart(2, '0')}`;​
  const unitClean = params.unitNumber.toUpperCase().replace(/\s+/g, '');​
  const zHeight = 
`${params.elevationBottomZ.toFixed(1)}-${params.elevationTopZ.toFixed(1)}M`;​
  return `${params.parcelUlpin2d}-${floorFormatted}-U${unitClean}-${zHeight}`;​
